ChatGPT Compatibility

Experimental 0.2.0~beta2. Disabled by default. Not device-tested.

A narrowly scoped RootHide experiment for iPhone16,2 on iOS 17.0, targeting official ChatGPT 1.2026.272. Successful installation, launch, and dot access have not been verified.

Download the RootHide package

In Sileo

Add or refresh https://chasesdavis.github.io/repo/, then search for ChatGPT Compatibility (Experimental). Publishing this package does not install it on your phone.

What changes

Beta 2 fixes beta 1's confirmed interception-order bug by handling the User-Agent when AppleMediaServices attaches it, after typed ChatGPT purchase metadata exists. Only identified single-product ChatGPT store requests and the target bundle's minimum-OS comparison qualify. Unknown or unsupported cases keep their original behavior. The tweak does not patch app files, modify signatures or receipts, bypass account access, or spoof global OS APIs.

The package requires existing Bootstrap daemon injection. It does not enable injection into ChatGPT or restart any process. It conflicts with LowerInstall and AppStoreTroller to avoid stacking broad spoofers.

Enable or remove

After an installation you choose to perform, open Settings → ChatGPT Compatibility. The experiment is off until you enable its switch. Beta 2 adds a Runtime status panel for daemon load, hook registration, and matching ChatGPT work. Turn the switch off before removing the package in Sileo. Already-loaded code leaves memory when the process exits normally; no restart is performed automatically.

This is not a confirmed update fix. It does not supply missing iOS 18 APIs or guarantee dots. An official App Store update replaces the installed app; removing the tweak does not undo that update.

Local verification

121 policy/ABI assertions and 36 mock hook-integration assertions passed, including the beta 1 interception-order regression. Both arm64 and arm64e slices built against the iOS 17 SDK. These checks do not establish real-device compatibility.
