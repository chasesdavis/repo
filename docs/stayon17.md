# StayOn17

Per-app iOS version gate bypass for iOS 17 roothide.

Install from https://chasesdavis.github.io/repo/ — package com.chasedavis.stayon17.

## CLI

stayon17-scan scan --bundle-id com.example.app
stayon17-scan enable com.example.app --spoof 18.0
